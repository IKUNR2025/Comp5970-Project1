Name: Don't Touch the Blocks

This is a 2D dodging game made with the Unity engine. Players move left and right to avoid falling blocks. Successfully dodging blocks scores points.

Controls：

A/D: Move left and right
Left/Right Arrow: Move left and right

Game Features：

1. Player Movement

2. Obstacle Generation

3. Collision Detection

4. Score Counter

5. Game Start and End Screens

6. Restart System

Additional Features：

I added obstacles of random sizes and varying falling speeds. The size and speed of each block are randomized, making the game more challenging and unpredictable.

Gameplay：

Move left and right to avoid falling blocks. The score increases when a block reaches the bottom without hitting the player. If the player touches a block, the game ends and a restart option appears.
